# The Quantum Data Relay Optimisation (Hard) Problem
## Overview
The problems states that managing a global network of `K` data centres is needed. Each data centre generates a stream of unsorted packet IDs. The goal is to process, merge, compress, and route these packets under strict network constraints. My solution to this leetcode type problem is given in Python, unfolding the heap-merge + cost-matrix + DP pipeline.

## Problem Description
You are given a 2D integer array streams of size `K`, where `streams[i]` is an unsorted list of packet IDs generated by data centre `i`. You are also given an integer `max_boxes`.
To successfully relay the data, you must perform the following operational pipeline:
1. Merge Streams: Sort each stream, then combine all `K` sorted streams into a single globally sorted master array, `master_stream`.
2. Segment Compression: You have up to `max_boxes` compression units. Each unit can compress a contiguous subarray of `master_stream`. The 'compression value' of a subarray from index `i` to `j` is calculated as:
`Value(i, j) = (master_stream[j] - master_stream[i]) × (j - i + 1)`\
Constraint: You cannot compress overlapping segments, and each selected segment must have a length of at least 2.

Return the maximum total compression value you can achieve across the `master_stream` using at most `max_boxes` non-overlapping segments.
